# Трекер задач (Task Tracker)

Учебное приложение для курса «Практический курс веб-разработки: React, TypeScript, Node и Supabase».

Петренко Александр Кириллович 24ИС

## Тема и сценарий
Task Tracker помогает студенту вести личные задачи. Пользователь добавляет задачу, указывает срок и приоритет, меняет статус и находит просроченные записи.

## Стек
React, TypeScript, Vite (позже: Supabase, Node.js API)

## Версия Node
26.10.0 

## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:
```bash
npm run build
npm run preview
```

## Что работает сейчас
Начальный экран с названием, описанием и заглушкой списка задач.

## Текущие ограничения
Данных, форм, навигации, авторизации и backend пока нет: они будут добавлены в следующих лабораторных.
