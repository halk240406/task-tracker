# Ход работы

## ЛР 1. Старт проекта
Создан проект React + TypeScript + Vite, заменён стартовый экран, проект опубликован в Git-репозитории.

Проверка:
1. `cd frontend && npm ci && npm run dev`: экран открывается без ошибок.
2. Временная ошибка типа в `appTitle` (число вместо строки): `npm run build` падает.
3. После исправления `npm run build` проходит.
4. `npm run preview`: готовая сборка открывается.
5. Клон репозитория в `course-app-check`: `npm ci` и `npm run build` проходят.

Коммит ЛР 1: 9976332

## ЛР 2. Страницы приложения и навигация
Добавлены маршруты списка, карточки, создания и неизвестного адреса. Список и карточка работают через общий массив данных, а навигация использует React Router.

Проверка:
1. `/` редиректится на `/tasks`.
2. Список и карточки открываются по ссылкам и прямому URL.
3. `/tasks/new` и `/unknown` показывают отдельные страницы.
4. `npm run build` проходит после добавления маршрутизатора.

## ЛР 3. Формы и локальное состояние
Добавлены формы создания и редактирования, проверка ввода, общий список в `App`, удаление через подтверждение, а также локальный фильтр по статусу. Данные сохраняются в состоянии React и не привязываются к `localStorage`.

Проверка:
1. Создание новой записи через форму и переход на карточку.
2. Редактирование полей и обновление карточки и списка.
3. Отмена без сохранения не меняет данные.
4. Пустое название, отсутствие срока и нарушенное правило для завершённой задачи показывают ошибку без потери введённых значений.
5. Фильтр по статусу работает и сбрасывается.
6. Удаление и проверка неизвестной записи/адреса редактирования.
7. `npm run build` проходит после изменений.

Данные в проекте остаются временными: после обновления страницы приложение возвращается к демонстрационному набору из ЛР 2.
